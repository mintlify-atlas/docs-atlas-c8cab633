ContaFácil es una aplicación web contable full-stack que cubre todas las etapas del ciclo contable: libros diarios, mayorización, balance de comprobación, estado de resultados, balance general y control de inventario con Kardex. Construida sobre Node.js/Express con Supabase PostgreSQL como base de datos, está diseñada para gestionar múltiples empresas con datos completamente aislados por organización.

## Primeros pasos

<Steps>
  <Step title="Instala las dependencias">
    Requiere Node.js 22 o superior. Clona el repositorio e instala con `npm install`.
  </Step>
  <Step title="Configura Supabase">
    Copia `.env.example` a `.env` y define `SUPABASE_DB_URL` con la URL del Session pooler de tu proyecto Supabase.
  </Step>
  <Step title="Ejecuta las migraciones">
    Corre los tres archivos SQL en el editor de Supabase: `001_supabase_empresas_libros_dinamicos.sql`, `002_balance_comprobacion.sql` y `003_kardex.sql`.
  </Step>
  <Step title="Inicia el servidor">
    Ejecuta `npm start`. La API estará disponible en `http://localhost:3000/api` y la interfaz web en `http://localhost:3000`.
  </Step>
</Steps>

<Note>
  La primera empresa (`id_empresa = 1`) se crea automáticamente con la migración inicial. Puedes registrar empresas adicionales mediante el endpoint `POST /api/registro`.
</Note>
