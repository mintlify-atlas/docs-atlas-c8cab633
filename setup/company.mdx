Every installation of ContaFácil revolves around one or more **empresas** (companies). Each empresa owns its own set of libros diarios, asientos, and kardex movements — data from one empresa is never mixed with another. The first migration seeds a default empresa (`id_empresa = 1`) so you can start using the API immediately; this page explains how to populate it with your real company information.

## Company Data Model

The `empresas` table holds all the profile information for a company. The fields available are:

<ParamField path="id_empresa" type="integer">
  Auto-generated primary key. Assigned by the database using an identity column (`GENERATED BY DEFAULT AS IDENTITY`). You do not set this manually.
</ParamField>

<ParamField path="nombre_legal" type="string" required>
  The official registered legal name of the company. This field is **required** — every API call that writes empresa data validates its presence. Example: `"Distribuidora La Palma, S.A. de C.V."`.
</ParamField>

<ParamField path="nombre_comercial" type="string">
  The trade name or brand name under which the company operates, if different from the legal name. Example: `"La Palma Distribuciones"`.
</ParamField>

<ParamField path="nit" type="string">
  Número de Identificación Tributaria — the tax identification number issued by the Salvadoran tax authority (DGII). Example: `"0614-123456-789-0"`.
</ParamField>

<ParamField path="nrc" type="string">
  Número de Registro de Contribuyente — the VAT registration number. Required for companies registered for IVA in El Salvador. Example: `"123456-7"`.
</ParamField>

<ParamField path="giro_comercial" type="string">
  The business activity or industry classification. Used on official accounting documents. Example: `"Venta al por mayor de productos alimenticios"`.
</ParamField>

<ParamField path="direccion" type="string">
  The company's registered physical address. Example: `"Calle Principal #42, Colonia Escalón, San Salvador"`.
</ParamField>

<ParamField path="telefono" type="string">
  Contact phone number. Stored as free-form text to accommodate local and international formats. Example: `"2222-3333"`.
</ParamField>

<ParamField path="email" type="string">
  The company's public contact email address. This is the business contact email — not the admin login credential. Example: `"contacto@lapalma.com.sv"`.
</ParamField>

<ParamField path="logo" type="string">
  A URL pointing to the company logo image. Accepts any publicly accessible URL string.

  <Tip>
    Upload your logo to **Supabase Storage**, make the bucket public, and paste the resulting public URL here. This keeps your logo on the same infrastructure as your data and avoids external image hosting dependencies.
  </Tip>
</ParamField>

<ParamField path="moneda" type="string" default="USD">
  The currency code used by this empresa. Defaults to `"USD"` (US Dollar), which is the official currency in El Salvador. Change this if your deployment targets a different country or currency.
</ParamField>

<ParamField path="pais" type="string" default="El Salvador">
  The country of registration. Defaults to `"El Salvador"`. Used for labeling on printed reports.
</ParamField>

<ParamField path="estado" type="string" default="ACTIVO">
  Lifecycle state of the empresa record. Accepted values are `"ACTIVO"` or `"INACTIVO"`. Only `ACTIVO` empresas are returned by the `GET /api/empresa` endpoint.
</ParamField>

## Retrieving the Company Profile

```bash
GET /api/empresa?idEmpresa=1
```

Returns the company profile along with the `login_email` of the active admin user. Example response:

```json
{
  "id_empresa": 1,
  "nombre_legal": "Empresa principal",
  "nombre_comercial": null,
  "nit": null,
  "nrc": null,
  "giro_comercial": null,
  "direccion": null,
  "telefono": null,
  "email": null,
  "logo": null,
  "moneda": "USD",
  "pais": "El Salvador",
  "login_email": "admin@example.com"
}
```

The `login_email` field is sourced from the `usuarios` table — specifically the first `ACTIVO` user with `rol = 'admin'` linked to this empresa. It is read-only in this response; update it via the `PUT` endpoint described below.

## Updating the Company Profile

```bash
PUT /api/empresa/:idEmpresa
Content-Type: application/json
```

`nombre_legal` is the only required field. All other company fields are optional — omitted fields are saved as `NULL`.

### Example request

```bash
curl -X PUT http://localhost:3000/api/empresa/1 \
  -H "Content-Type: application/json" \
  -d '{
    "nombre_legal":     "Distribuidora La Palma, S.A. de C.V.",
    "nombre_comercial": "La Palma Distribuciones",
    "nit":              "0614-123456-789-0",
    "nrc":              "123456-7",
    "giro_comercial":   "Venta al por mayor de productos alimenticios",
    "direccion":        "Calle Principal #42, Colonia Escalón, San Salvador",
    "telefono":         "2222-3333",
    "email":            "contacto@lapalma.com.sv",
    "logo":             "https://PROJECT_REF.supabase.co/storage/v1/object/public/logos/lapalma.png",
    "moneda":           "USD",
    "pais":             "El Salvador"
  }'
```

On success the API responds with the full updated empresa object (same shape as the `GET` response).

## Admin Credentials

The `PUT /api/empresa/:idEmpresa` endpoint also accepts two optional fields that update the admin user record in the `usuarios` table within the same database transaction:

<ParamField body="login_email" type="string">
  New email address for the admin user. Must be unique across all users — if the address is already taken by another account the API returns `400` with the message `"El correo de acceso ya está en uso por otro usuario."`.
</ParamField>

<ParamField body="login_password" type="string">
  New password for the admin user. Only updated when this field is present **and** non-empty. If omitted or blank, the existing password is left unchanged.
</ParamField>

### Example — update admin credentials only

```bash
curl -X PUT http://localhost:3000/api/empresa/1 \
  -H "Content-Type: application/json" \
  -d '{
    "nombre_legal":    "Distribuidora La Palma, S.A. de C.V.",
    "login_email":     "nuevo-admin@lapalma.com.sv",
    "login_password":  "NuevaContraseña2025!"
  }'
```

<Warning>
  Passwords are currently stored in plain text in the database. Avoid setting sensitive passwords until a hashing mechanism (e.g. `bcrypt`) has been added to the `actualizarEmpresa` model function. See the [Database Setup](/setup/database) page for more context.
</Warning>
